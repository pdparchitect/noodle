# Noodle Enterprise

Managing Noodle with a configuration profile from a device management system: the code that reads
and enforces the profile's settings, the Jamf Pro schema and a sample profile in
[`Profiles/`](Profiles/), and the [deployment guide](Deployment.md) for administrators.
