# Computer icon artwork

Generated with the built-in image generation tool, using `Support/AppIcon.png`
from standard Noodle as the visual reference. The project source is
`Computer/Support/AppIcon.png`; `MakeIcon.swift` packages its size variants.

Prompt:

> Use case: style-transfer. Asset: final macOS application icon for Noodle Computer, square 1024x1024 PNG. Reference image: existing Noodle application icon, authoritative palette and brand mark/style reference. Create its sibling Noodle Computer icon. Preserve the same saturated deep cobalt/royal blue softly textured squircle tile, creamy warm ivory, simple thick rounded noodle-like strokes, quiet friendly minimal character. Distinguish Computer with a bold elegant rounded desktop monitor outline and short rounded stand in that same cream; inside the screen place the reference's distinctive lowercase arch-shaped noodle n mark (one rounded arch with curled right foot), scaled clearly and generously. Balanced centered silhouette readable at small dock sizes. No terminal prompt, no extra text, no lettering other than the existing noodle n symbol, no additional colors, no photoreal hardware, no 3D extrusion, no decorative objects. Maintain reference palette precisely. Genuinely transparent area outside rounded square, no baked-in white or colored rectangular background. Tile fills nearly entire square with a small consistent transparent margin, no giant border.
