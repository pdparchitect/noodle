# Noodle Mobile

Noodle for iPhone and iPad. People pair it with their Noodle Hub and use the agents
they keep there. It reaches the Hub through `Shared/HubLink`, as the Mac apps do;
change the link and its protocol there, not here.

Mobile is released on its own, through TestFlight, from `VERSION` and `CHANGELOG.md`
in this folder. Do not publish releases without the user's explicit request.

The Xcode project is generated by Tuist from `Project.swift`; change that, never the
generated project. `scripts/mobile.sh` runs, tests and packages the app.

README.md is for people using the app; do not document code in it. Follow the
`no-code-docs` skill.
