# Rook

An incubating tool, versioned on its own from `VERSION` and `CHANGELOG.md` in this
folder. It has no release yet. Do not publish releases without the user's explicit request.

Rook is its own app on Noodle's core and runtime (agents, groups, harnesses, Agent Host, tool broker,
shared settings panes). Noodle's own code never mentions Rook. Rook also compiles many of Noodle's app
files directly (the composer, transcript, sheets, profiles, scenarios and more), listed in `Project.swift`, so
a change to one of them reaches both apps. `RookCore` holds what Rook adds and draws nothing; `Sources/RookApp` is the app.

The Xcode project is generated by Tuist from `Project.swift`; change that, never the generated project.
