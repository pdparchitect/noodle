# Pion

An incubating tool, versioned on its own from `VERSION` and `CHANGELOG.md` in this
folder. It has no release yet. Do not publish releases without the user's explicit request.

Pion is its own app on Noodle's core and runtime (agents, groups, harnesses, Agent Host, tool broker,
shared settings panes). Noodle's own code never mentions Pion. Pion reuses a few self-contained files of
Noodle's app (the composer, dictation and transcript scrolling) by compiling them directly; they are
listed in `Project.swift`. `PionCore` holds what Pion adds and draws nothing; `Sources/PionApp` is the app.

The Xcode project is generated by Tuist from `Project.swift`; change that, never the generated project.
