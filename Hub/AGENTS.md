# Noodle Hub

A menu bar app that keeps shared harness logins and runs the bots people keep on it,
for the devices paired with it. It runs bots with Noodle's own runtime from the root
package, and devices reach it through `Shared/HubLink`; change that code there, not here.

The Hub is released on its own, from `VERSION` and `CHANGELOG.md` in this folder; Noodle
integration notes go in the root changelog. Do not publish releases without the user's
explicit request.

Devices already released must keep working: a field added to the link protocol decodes
with a default, and the version 1 tests keep passing. The Hub's data stays apart from
Noodle's, in its own container.

The Xcode project is generated by Tuist from `Project.swift`; change that, never the
generated project.

README.md is for people using the Hub; do not document code in it. Follow the
`no-code-docs` skill.
