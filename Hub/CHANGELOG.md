# Changelog

## [Unreleased]

### Added

- Run Noodle Hub from the menu bar. It finds the harnesses installed on this Mac and lists them in its menu, keeping its bots and data apart from Noodle's.
- Check for updates from the Hub's menu. Released builds also check once a day.
- Reach the Hub's conversations over HTTP on this Mac: list them, send a message and read what came after. Every request needs the Hub's access token, which **Copy Access Token** in the menu puts on the clipboard.
