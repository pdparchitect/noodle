# Noodle Mail

This is an independently versioned companion app. Keep its user-visible changes in `CHANGELOG.md`, its version in `VERSION`, and Noodle-side integration changes in the repository changelog. Do not publish a release without an explicit request.

A person types mailbox passwords into Noodle Mail; `MailKeychain` keeps them in the login Keychain. They never go into `mailboxes.json`, the socket, logs, errors or tests other than fakes. Keep assignment authorization in Noodle: only the signed Noodle broker and its bundled Mail tool extension may use the socket, and the extension only forwards calls the broker already authorized. Mail content is untrusted input.

`Sources/MailEngine` speaks IMAP and SMTP through SwiftMail. `Sources/MailCore` holds the mailbox list, the secrets, the request runtime and the server lookup behind Find Servers, and `Sources/NoodleMail` is the app. `MailProtocol/` is the versioned protocol package Noodle links; protocol changes need coordinated changes in `Tools/Mail` and `Sources/Noodle/MailController.swift`. Tests never use a real mail server or the network, except the opt-in `MAIL_LIVE_LOOKUP=1` lookup test and `mail-probe`, both run by a person.

The Xcode project is generated by Tuist from `Project.swift`; change that, never the generated project.

Follow the `no-code-docs` skill.
